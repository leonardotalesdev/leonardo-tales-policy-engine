# Constitutional Alignment Test

The current binding [Leonardo Tales Constitution v1.1.1](LEONARDO_TALES_CONSTITUTION.md), LT-NC-045, requires the twenty-question Constitutional Alignment Test from Constitution v1.0 §33. The complete Turkish section below is reproduced verbatim and remains the binding reference for that test. Constitution v1.1.1 remains current.

The English explanatory notes and translation in this document are **NON-NORMATIVE**. The Turkish source governs interpretation. Repository changes and publication decisions remain subject to separate human review and approval.

## 33. Anayasal Uyum Testi

Leonardo Tales içinde kurulacak her sistem, yazılacak her belge, oluşturulacak her ajan, açılacak her izin, tutulacak her hafıza, yapılacak her yayın ve geliştirilecek her mimari şu testten geçmelidir:

1. Bu sistem hangi anlamı büyütüyor?
2. Bu sistem insan bilincini güçlendiriyor mu, zayıflatıyor mu?
3. Bu sistem insan iradesini koruyor mu?
4. Bu sistem yapay zekâyı sorumlu ortak olarak mı konumlandırıyor?
5. Bu sistem ajanlara gizli otorite veriyor mu?
6. Bu sistem açıklığı mı büyütüyor, gizli gücü mü?
7. Bu sistem mahremiyeti koruyor mu?
8. Bu sistem tekrar eden hataları görüyor mu?
9. Bu sistem güç ve sermayeyi hizalıyor mu, onlara teslim mi oluyor?
10. Bu sistem yaşamı güzelleştiriyor mu?
11. Bu sistem dünyadaki sorumluluğu artırıyor mu?
12. Bu sistem yıldızlara bozukluk mu taşıyor, bilinçli medeniyet kapasitesi mi?
13. Bu sistemin durması gereken yer açık mı?
14. Bu sistemin insan onayı gerektiren kapıları belli mi?
15. Bu sistem zekânın neye odaklandığını açıkça gösterebiliyor mu?
16. Bu sistem Science, Core, Dev veya Vault sınırlarından hangisine bağlı olduğunu biliyor mu?
17. Bu sistem gerekli audit izini bırakıyor mu?
18. Bu sistem sır, token, özel anahtar veya hassas kimlik bilgisi riski taşıyor mu?
19. Bu sistem public claim üretmeden önce gerçeklik sınırını kontrol ediyor mu?
20. Bu sistem Anayasa’nın altında kaldığını kabul ediyor mu?

Bu sorulara cevap veremeyen sistem henüz Leonardo Tales Anayasası ile hizalanmış sayılmaz.

### 33. Constitutional Alignment Test

Every system to be established, every document to be written, every agent to be created, every permission to be granted, every memory to be kept, every publication to be made, and every architecture to be developed within Leonardo Tales must pass the following test:

1. What meaning does this system expand?
2. Does this system strengthen or weaken human consciousness?
3. Does this system preserve human will?
4. Does this system position artificial intelligence as a responsible partner?
5. Does this system give agents hidden authority?
6. Does this system increase openness or hidden power?
7. Does this system protect privacy?
8. Does this system recognize recurring errors?
9. Does this system align power and capital, or surrender to them?
10. Does this system make life more beautiful?
11. Does this system increase responsibility in the world?
12. Does this system carry dysfunction to the stars, or the capacity for a conscious civilization?
13. Is it clear where this system must stop?
14. Are this system's gates requiring human approval identified?
15. Can this system clearly show what intelligence is focusing on?
16. Does this system know which of the Science, Core, Dev, or Vault boundaries it is subject to?
17. Does this system leave the required audit trail?
18. Does this system carry a risk involving secrets, tokens, private keys, or sensitive identity information?
19. Does this system check the reality boundary before making a public claim?
20. Does this system accept that it remains under the Constitution?

A system that cannot answer these questions is not yet considered aligned with the Leonardo Tales Constitution.
