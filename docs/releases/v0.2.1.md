# Leonardo Tales Policy Engine v0.2.1

Package: `@leonardo-tales/policy-engine@0.2.1`

## Purpose

v0.2.1 is a distribution-metadata patch for public npm publication.

It does not change the Policy Engine evaluation implementation or the `tales-actions-v1` action-profile contract. The package source behavior remains the v0.2.0 implementation; the repository's post-v0.2.0 changes before this patch are documentation-only verified-integration evidence.

## Distribution changes

- removes the package-level `private: true` publication block;
- declares public scoped-package access through `publishConfig.access = "public"`;
- adds npm-facing repository and maintainer metadata;
- documents direct npm installation;
- adds a release-validation workflow.

## Security boundary

This package evaluates caller-supplied policy facts only.

It does not execute tools, authenticate a human, verify approval identity, access credentials, persist audit records, or grant execution authority. An `allow` result remains an evaluation result rather than permission to execute.

## Release rule

A GitHub commit, tag, Release or this document does not prove npm publication. npm availability must be verified against the public registry.

The first npm publication requires separate npm account/scope authorization. No npm credential is stored in this repository.
